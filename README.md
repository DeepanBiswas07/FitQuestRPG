# FitQuestRPG

FitQuestRPG is an immersive calisthenics routine generator and progressive skill-tree builder built with HTML, CSS, and JavaScript. It turns physical training into a medieval RPG quest by mapping real-world calisthenics skills to a progressive, visual grid system.

## Live Demo

[Open FitQuestRPG](https://deepanbiswas07.github.io/FitQuestRPG/)

## Features

- Choose your core specialization class (Goliath, Acrobat, Monk)
- Track progress across an interactive 100+ skill tree
- Unlock glowing animated SVG pathing as you master pre-requisites
- Forge custom workouts (Practice, Smart, and Challenge modes)
- Engage in interactive fantasy boss battles with hit splashes and screen shakes
- Enjoy procedurally generated, offline music themes (Tavern and Battle)
- Static client-side frontend with zero build steps or backend required

## Branches Included

- **Push**: Wall Push-ups to advanced One-Arm Push-ups
- **Pull**: Incline Rows to advanced Front Lever Rows and One-Arm Chin-ups
- **Core**: L-Sits, Dragon Flags, and Ab Wheel rollouts
- **Legs**: Assisted Squats to advanced Pistol and Shrimp Squats
- **Wall**: Handstand balance, Wall Walks, and Handstand Push-ups
- **Mobility**: Joint warmups, active stretches, and splits prep
